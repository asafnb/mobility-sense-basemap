# חבילה אזורית: ירושלים (`jerusalem`)

שכבות שרלוונטיות רק לירושלים. הן לא חלק ממפת הבסיס הארצית (מ־v5), ונטענות רק כשפרויקט מצמיד את החבילה או בתצוגה מקדימה.

- הגדרה: `region.json` (שכבות, קבוצות, מקרא, סימניות, bbox). גרסאות קפואות: `j1/manifest.json`, ...
- יומן: `CHANGELOG.md`.
- תצוגה מקדימה: `python scripts/build_project.py --region jerusalem --base v5` ← `dist/region_jerusalem_j1__base_v5.geolibre`.
- הצמדה בפרויקט: `"regions": [{"id": "jerusalem", "version": "j1"}]`.
